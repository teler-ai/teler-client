# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues, pull requests or
discussions.

Report them privately through the [teler.ai contact form](https://teler.ai/contact),
choosing the **Security** topic. Include the affected client and version, your
operating system, the steps to reproduce and the impact you expect. Leave out
real credentials and other people's data. A person reads every report.

This also applies to problems in the Teler service that you find while using
these clients.

## Supported versions

Security fixes go into the latest release of the CLI and of Teler Desktop.
